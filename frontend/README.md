# Front-End

Este é o front-end do projeto **Finance Tracker**, desenvolvido com **Vite**, **Vue**, **Shadcn**, **Axios** e **Pinia**. Ele fornece a interface do usuário para o gerenciamento financeiro, permitindo que os usuários interajam com as funcionalidades do sistema.

## Estrutura de Pastas

Abaixo está a estrutura de pastas do projeto, com uma breve descrição de cada pasta:

### Descrição das Pastas

- **`src/assets/`**: Contém arquivos estáticos, como imagens e ícones.
- **`src/components/`**: Contém componentes reutilizáveis, como botões, cabeçalhos e formulários.
- **`src/pages/`**: Contém as páginas principais da aplicação, como `Home`, `Login` e `Dashboard`.
- **`src/stores/`**: Contém os stores do Pinia para gerenciamento de estado global.
- **`src/services/`**: Contém funções para realizar chamadas à API do back-end.
- **`src/styles/`**: Contém arquivos de estilos globais e específicos para componentes.
- **`src/routes/`**: Contém rotas da aplicação.
- **`src/services/`**: Contém todas as chamadas para realizar uma requisição para o Back-End.
- **`src/App.vue`**: Componente principal que define a estrutura da aplicação.
- **`src/main.ts`**: Arquivo de entrada que inicializa o Vue e configura o Pinia.

## Dependências

### Dependências de Produção

- **[axios](https://github.com/axios/axios)**: Biblioteca para realizar requisições HTTP.
- **[vue](https://vuejs.org/)**: Framework progressivo para construção de interfaces de usuário.
- **[pinia](https://pinia.vuejs.org/)**: Biblioteca para gerenciamento de estado no Vue.
- **[shadcn](https://shadcn.dev/)**: Biblioteca de componentes estilizados para Vue.

### Dependências de Desenvolvimento

- **[@vitejs/plugin-vue](https://github.com/vitejs/vite/tree/main/packages/plugin-vue)**: Plugin oficial do Vue para Vite.
- **[vite](https://vitejs.dev/)**: Ferramenta de build rápida para projetos front-end.
- **[typescript](https://www.typescriptlang.org/)**: Superset do JavaScript que adiciona tipagem estática.
